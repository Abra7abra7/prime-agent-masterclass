# PRED SPUSTENIM:

#   2. Nahraď AVATAR_ID a VOICE_ID za tvoje hodnoty z HeyGen dashboardu

#   4. Voice ID nájdeš v https://app.heygen.com/voices

# POZNÁMKA: HeyGen API v2 podporuje streaming a async vytváranie videí.
#           Nižšie sú curl príkazy pre klasické dávkové generovanie.

# Krok 1: Vytvorenie avatar videa (classic batch)
curl -X POST "https://api.heygen.com/v2/video/generate" \
  -H "X-Api-Key: $HEYGEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "video_name": "m02_l01_prompt-engineering-pre-agentov",
    "dimension": { "width": 1920, "height": 1080 },
    "avatar_id": "YOUR_AVATAR_ID",
    "voice_id": "YOUR_VOICE_ID",
    "input_text": "Vitaj v Module 3. Toto je modul, ktorý z teba spraví skutočného power-usera. Skills sú to, čo mení Prime Agenta z univerzálneho nástroja na tvojho osobného špecialistu. Skills = znovupoužiteľné balíčky expertízy. Vytvoríš raz, používaš navždy. Skill v Prime Agentovi je balíček inštrukcií, ktorý agentovi hovorí, AKO niečo robiť. Nie ČO robiť – to povieš ty. Skill definuje POSTUP. Skill = expertný postup zabalený do súboru. Agent ho načíta, aplikuje a ty dostaneš konzistentný výsledok – vždy. Poďme si ukázať, ako skill reálne funguje na príklade. Kvalitný skill = vieš presne, čo dostaneš, kedy a v akej kvalite. Ak to nie je jasné z SKILL.md, skill je zlý. Poďme preskúmať, aké skilly už máš k dispozícii.",
    "background": { "type": "color", "value": "#0a0a1a" },
    "avatar_style": "normal"
  }'
