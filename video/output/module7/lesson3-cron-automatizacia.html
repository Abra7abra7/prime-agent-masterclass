Prime Agent — Terminal
🛡️ Robustný scheduled task skript
#!/bin/bash # /scripts/agent-task.sh – s error handlingom export DEEPSEEK_API_KEY="sk-..." LOG_FILE="/logs/agent-$(date +%Y-%m-%d).log" prime-agent --prompt "..." >> $LOG_FILE 2>&1 if [ $? -ne 0 ]; then echo "⚠️ Agent task FAILED: $(date)" | \ mail -s "Agent Alert" ja@firma.sk # Retry s iným modelom prime-agent --provider anthropic \ --model claude-sonnet-4-20250514 \ --prompt "..." >> $LOG_FILE 2>&1 fi
🔑 Kľúčové prvky: ✓ Logovanie do súboru (s dátumom) ✓ Notifikácia pri zlyhaní (email) ✓ Retry s alternatívnym modelom ✓ Rate limiting a monitoring nákladov
