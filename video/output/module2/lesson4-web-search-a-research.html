Web Search vs Scraping

🔍 Web Search
Rýchla odpoveď
Prehľad zdrojov
Overenie faktov
Trendy a novinky
Konkurenčná analýza
→ ŠÍRKA (veľa zdrojov, rýchlo)
🕸️ Scraping
Extrakcia špecifických dát
Plný text článkov
Monitorovanie zmien
Zber dát pre datasety
Hĺbková analýza obsahu
→ HĹBKA (detalné dáta)

🎯 4 techniky profíka

1. Presné vyhľadávanie s operátormi
"presná fráza" · site:github.com · -reddit · (CLI OR terminal)
2. Štruktúrované vyhľadávanie
Namiesto 1 širokého dotazu → 3 špecifické dotazy s rôznymi uhlami
3. Krížové overenie
5 zdrojov → porovnanie → zhody → syntéza. Jeden zdroj = jeden názor.
4. Iteratívny research
Prvé vyhľadávanie → analýza → identifikácia medzier → druhé vyhľadávanie → hlbšia analýza

📋 Šablóna research promptu

Preskúmaj [TÉMA]. Potrebujem:

1. [ČO konkrétne zistiť]

2. [AKÉ zdroje / obmedzenia]

3. [FORMÁT výstupu — report, tabuľka, zoznam]

4. [ČASOVÝ rámec — posledný rok, vždy aktuálne]

Cieľ jasný. Zdroje špecifikované. Formát definovaný. Časový rámec stanovený. Plus akčné odporúčanie.

Zhrnutie

✅ Web search = rýchly prehľad, scraping = hĺbková analýza

✅ Operátory: quotes, site:, -exclude

✅ Krížové overenie: viac zdrojov → syntéza

✅ Iteratívny research: prvé výsledky → lepšie otázky

✅ Research prompt = téma + čo + zdroje + formát + čas

Research s agentom = rýchlosť, šírka a hĺbka.
