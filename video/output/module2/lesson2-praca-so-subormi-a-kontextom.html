📁 Súbory ako palivo agenta

Agent bez súborov je ako kuchár bez surovín.

Naučíš sa agentovi efektívne dodať dáta — malé súbory, veľké súbory, celé projekty.

Toto je tá pravá sila agenta — reálne pracovať s tvojím kódom.

2 / 7

👁️ Ako agent „vidí" súbory

📖 Čítanie súborov
Malé súbory celé do kontextu. Stredné po častiach. Veľké — streaming, indexy.
✏️ Editácia súborov
edit skill = presná editácia. Bash = echo, cat. Python = open().write()
🖼️ Binárne súbory
Obrázky cez attach_image. PDF extrakcia textu cez bash nástroje.
📊 Kontextové okno = strop
Claude 200K, DeepSeek 128K, Gemini 2.5 1M tokenov. 1 token ≈ 0.5 slova (SK).

🔧 Praktické techniky

Refaktoring naprieč projektom
grep -r "oldFunction" → nájdi všetky výskyty → edit skill → grep overenie
CSV bez pandas (150 MB)
Python csv modul, čítať po riadkoch, inkrementálny zápis — memory-efficient
Zlúčenie dokumentácie
10× .md → extrahovať nadpisy → obsah → spojiť do docs.md

Vzorec: identifikuj → spracuj → over

🪟 Kontextové okno — stratégie

1. Chunking
„Spracuj prvých 500 riadkov, ulož, potom pokračuj..."
2. Sumarizácia
„Sumarizuj doterajší priebeh (200 slov) a pokračuj."
3. Indexovanie ⭐
grep -rn "def \|class " --include='*.py' > symbols.txt
Projekt 50 000 riadkov → index 3 000 riadkov
4. Kontextové súbory
„Vytvor context.md s kľúčovými informáciami, ktoré agent potrebuje."

✅ Best Practices

✅ ROB

  • Špecifikuj cestu k súborom
  • Chunking pri veľkých súboroch
  • Vytváraj medzivýstupy
  • Indexovanie pre veľké projekty
  • Špecifikuj formát extrakcie

❌ NEROB

  • Nenačítaj 50 MB naraz
  • „Tamten súbor" nefunguje
  • Agent nevidí mimo WD
  • Needituj binárne súbory

Zapamätaj si: identifikuj – spracuj – over. Pri veľkých dávkach: indexuj a chunkuj.
