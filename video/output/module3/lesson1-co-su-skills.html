🧩 Skills = super-schopnosti

Ak je Prime Agent smartfón, skills sú appky.

Bez nich je to skvelý hardvér. S nimi je to zariadenie, ktoré rieši presne TVOJE problémy.

Skills = znovupoužiteľné balíčky expertízy. Vytvoríš raz, používaš navždy.

2 / 7

📦 Čo presne je skill?

Skill = adresár so súborom SKILL.md
Voliteľne: Python kód (skill.py), assety, konfigurácie, závislosti

SKILL.md obsahuje:

📛 Názov a popis — kedy skill použiť
🔤 Trigger phrases — aké frázy skill spúšťajú
📋 Inštrukcie — krok-za-krokom postup pre agenta
📝 Príklady — konkrétne ukážky použitia
⚠️ Obmedzenia — na čo si dať pozor
3 / 7

🏗️ Ako skills fungujú v praxi

Príklad: Skill na code review

Používateľ:
„Sprav code review"
→
Agent načíta
code-review/SKILL.md
→
Skill = postup:
git diff → naming → DRY
→ error handling → testy

Bez skillu agent vytvorí generický text. So skillom vytvorí text podľa tvojej presnej šablóny.

⭐ Ako vyhodnotiť kvalitu

Dobrý skill:

  • Jasný trigger — presne vieš, kedy ho použiť
  • Detailné inštrukcie — krok-za-krokom
  • Konkrétne príklady — 2-3 ukážky výstupu
  • Definovaný výstup — aký formát, štruktúra, kvalita
  • Obmedzenia a edge cases

Zlý skill:

  • Príliš široký trigger: „marketing", „writing"
  • Vágne inštrukcie: „write good code"
  • Žiadne príklady, žiadny výstupný formát

Kvalitný skill = vieš presne, čo dostaneš, kedy a v akej kvalite.
