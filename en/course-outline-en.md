## Module 1: Introduction & Installation

**What the student learns:** Understand what Prime Agent is, its capabilities, and successfully install and configure it on their system. Get an overview of the agent's architecture, components, and basic terminology.

### Lessons

1. **What is Prime Agent and why you need it**
   - Introduction to Prime Agent as an autonomous AI agent for developers and marketers. Overview of key capabilities — from writing code to marketing automation to production deployment.

2. **Architecture and key components**
   - Explanation of the fundamental building blocks: IPython kernel, skills, sub-agents, continual harness, RLM runtime. How these components work together to execute tasks.

3. **Installation on macOS, Linux, and Windows**
   - Step-by-step installation of Prime Agent via npm, including Node.js version checks. Setting up system variables and solving the most common installation issues.

4. **API key and provider configuration**
   - Setting up LLM providers (DeepSeek, OpenAI, Anthropic, Google Gemini). API key configuration via `/login` and choosing the default model.

5. **First run and interface orientation**
   - Launching the agent in the terminal, first welcome message, navigating the CLI interface. Basic commands and how to communicate with the agent.

4. **Web search and research**

   - A guided project that combines everything from Module 2. Build a real automation from start to finish.
